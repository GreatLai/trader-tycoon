# 倒卖大亨 · 全面架构逻辑文档

> 版本：v1.2.3  
> 形态：纯前端静态网页游戏（无后端）  
> 入口：`index.html`

---

## 1. 游戏概述

玩家扮演一名小商人，以 5000 元启动资金，在 90 天内通过低买高卖积累财富。  
游戏没有固定通关金额，财富每翻 10 倍触发一次评级；破产或 90 天到期即结束。

核心体验：
- 随机感遍布整个游戏
- 惊喜制造多巴胺，惊吓提供紧张感
- 事件叙事服务于惊喜/惊吓

## 2. 核心循环

```
打开页面
  ├─ 有存档 → 自动继续
  └─ 无存档 → 自动进入开场剧情
        ↓
第 1 天开始
  ├─ 查看今日市场（5 种商品）
  ├─ 查看突发事件 / 国际新闻
  ├─ 买入 / 卖出（当天不限次数）
  ├─ 点击「进入下一天」
  │    ├─ 结算每日支出
  │    ├─ 抽取今日商品
  │    ├─ 生成突发事件
  │    ├─ 推进生态事件
  │    ├─ 更新价格
  │    ├─ 记录走势/历史
  │    └─ 检查破产/到期
  └─ 循环
```

## 3. 技术架构

### 3.1 文件结构

```
trade-game-v2/
├── index.html          # 页面结构 + 资源引用
├── css/style.css       # 全部样式
├── js/
│   ├── config.js       # 配置、商品、里程碑、生态事件数据
│   ├── utils.js        # 工具函数、市场抽取
│   ├── state.js        # 游戏状态、基础查询
│   ├── eco.js          # 生态事件辅助
│   ├── events.js       # 突发事件 + 价格更新
│   ├── trading.js      # 买卖、贷款
│   ├── game.js         # 推进日期、结算、里程碑
│   ├── save.js         # 存档/读档
│   ├── ui.js           # 渲染、弹窗、走势图、历史
│   └── main.js         # 初始化、交互、开场、版本更新
├── version.json        # 线上版本检查
└── deploy.ps1          # GitHub 部署脚本
```

### 3.2 加载顺序

```
config → utils → eco → state → events → trading → game → save → ui → main
```

使用经典 `<script>` 加载，支持直接 `file://` 打开，也支持 GitHub Pages 托管。

### 3.3 分层关系

```
UI 层（ui.js / main.js）
  ↓
应用层（main.js：GameController / 事件委托 / 弹窗队列）
  ↓
系统层（market / events / eco / trading / economy / milestone）
  ↓
State Store（state.js）
  ↓
Save / Config（save.js / config.js）
```

## 4. 数据模型

### 4.1 核心 State

```js
state = {
  day, cash, loan, capacityLevel,
  prices, prevPrices, factors,
  lastSeenPrice, prevSeenPrice,
  inventory, costBasis,
  events, eco, ecoPopup,
  dailyHistory, priceHistory, chartGood,
  highestMilestone, availableGoods,
  logs, gameOver
}
```

### 4.2 商品 GOODS

每个商品：
```js
{
  id, name, icon, base, vol, tier
}
```

tier 分为：
- low：低价高波动
- mid：中价中波动
- high：高价低波动
- ultra：超高价值，跌多涨少，一涨很夸张（10M 解锁）

### 4.3 生态事件 ECO_EVENTS

每棵生态事件树：
```js
{
  name, unlock, goods,
  announce: { title, desc },
  A: [
    { news, mults, B: [
      { news, mults, C: [
        { news, mults, super? }
      ]}
    ]}
  ]
}
```

当前生态事件：
1. 全球干旱
2. 能源危机
3. 科技热潮
4. 金融风暴
5. 供应链断裂
6. 稀世收藏热潮（10M 解锁）
7. 太空竞赛（10M 解锁）

## 5. 子系统逻辑

### 5.1 市场系统

- 每天从已解锁商品中随机抽取 5 种
- 未达到 10M 时，ultra 商品不会出现在市场
- 商品是否出现与前一天无关，完全随机

### 5.2 价格系统

价格生成围绕基础价，使用“倍数因子”：

```
价格 = 基础价 × factor
```

每日更新：
- 普通日：factor 限制在 0.8 ~ 1.2（±20% 硬边界）
- 突发事件：直接落到 `基础价 × 事件倍率`
- 生态事件：围绕 `事件开始价 × 累计倍率` 过渡

### 5.3 突发事件

- 每天 0~3 个
- 只作用于今天上架且曾经出现过的商品
- 生态事件第 2 天起，受影响商品不参与突发事件
- 事件方向概率可按档位调整，ultra 商品利好概率仅 30%

### 5.4 生态事件

#### 时间轴

```
第 1 天：国际新闻宣告（特殊弹窗，最后弹出）
第 2 天：A 结果（3 选 1）
第 4 天：B 结果（3 选 1）
第 7 天：C 最终结果（3 选 1）
第 8 天：事件结束
```

#### 规则

- 同一时间只有 1 个生态事件
- 第 8~83 天每天 20% 概率触发新生态事件
- 第 84~90 天不再触发新事件，已触发的可正常完结
- 受影响商品第 2~7 天禁用随机涨跌和突发事件
- 受影响商品在市场中以紫色边框标识
- 生态事件倍率锚点 = 事件开始价
- 弹窗统一为「国际新闻」，不显示“生态事件/阶段/结束”

### 5.5 交易系统

- 买入：消耗现金，增加库存，受仓库容量限制
- 卖出：增加现金，减少库存
- 记录持仓成本，显示持仓盈亏
- 档位：1 / 10 / 100 / 满仓；卖：1 / 10 / 100 / 全卖

### 5.6 经济系统

- 每日仓库管理费：库存 × 0.05
- 贷款日利率：0.5%
- 现金不足时自动转为贷款
- 总资产 = 现金 + 库存已知价值 - 贷款
- 总资产 ≤ 0 或第 90 天结束 → 游戏结束

### 5.7 成长系统

- 财富里程碑每 10 倍提升一次评级
- 10M 里程碑解锁 ultra 商品和对应生态事件

### 5.8 存档系统

- localStorage 自动保存
- 有存档自动继续
- 版本更新按钮：检查 version.json，确认更新后清档并刷新

## 6. 关键规则总结

| 规则 | 内容 |
|---|---|
| 每日上架 | 5 种，随机 |
| 普通日价格边界 | 基础价 ±20% |
| 突发事件 | 突破 ±20%，按基础价倍率 |
| 生态事件 | 突破 ±20%，按事件开始价累计倍率 |
| 商品冲突 | 一个商品一天最多被一个事件影响 |
| 首次出现商品 | 当天不触发突发事件 |
| 生态事件触发 | 第 8~83 天 20%/天，同时只能 1 个 |
| ultra 解锁 | 总资产 ≥ 10,000,000 |
| 结束条件 | 破产 / 90 天到期 |

## 7. 平衡参数速查

| 档位 | 日常上涨概率 | 日常下跌概率 | 事件利好倍率 | 事件利空倍率 |
|---|---|---|---|---|
| low | 8% | 5% | 2.5~4 | 0.2~0.4 |

| high | 3% | 2% | 1.5~2 | 0.4~0.6 |

## 8. 部署与更新

- 托管：GitHub Pages
- 链接：`https://greatlai.github.io/trader-tycoon/`
- 更新流程：
  1. 修改本地代码
  2. 更新 `APP_VERSION` 和 `version.json`
  3. 更新 `index.html` 资源版本号 `?v=x.x.x`
  4. 提交并推送 GitHub
  5. Pages 自动构建
  6. 玩家点“版本更新”同步

## 9. 扩展点

- 新增商品：在 `config.js` GOODS 添加
- 新增生态事件：在 `config.js` ECO_EVENTS 添加
- 新增事件类型：实现独立 System 并通过 EventCoordinator 接入
- 新增成长系统：在 `game.js` / `ui.js` 添加对应模块
- 新增存档迁移：在 `save.js` 增加版本迁移逻辑
