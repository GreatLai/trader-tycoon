# 通商令与职业文案统一设计

## 目标

为所有职业增加每局三次的通用交易手段“通商令”，让玩家能够主动盘活未上架库存并承担一次不可控的重新报价。同时重写全部职业相关界面文案：局外简洁、有角色气质，局内完整公开概率、倍率、冷却、费用和限制。

## 通商令

- 所有职业每局获得 3 次，独立于职业主动技能，不共享冷却。
- 只能选择当前持有库存且当天未上架的商品。
- 使用后商品追加到当天货架，不替换原有 6/7 个货架位置，只持续到当天结束。
- 商品通过现有通用价格引擎重新报价，不允许玩家选择涨跌方向。
- 有 15% 概率触发一次普通突发事件；事件沿用商品档位、商品特质、6% 稀有事件概率、职业事件修正和统一方向价格规则。
- 生态行情期间仍可使用。未触发突发事件时按当前生态阶段定价；触发突发事件时由当日突发价格生效，下一天继续原生态事件。
- 临时上架后允许正常买入和卖出。
- 同一商品可在不同日期重复使用；允许同一天连续消耗多次。
- 无合法目标、游戏已经结束或目标状态在确认前发生变化时不消耗次数。

局内按钮显示 `通商令 3 / 3`。辅助文案固定为：

> 让一件压仓货重新报价并加入今日市场，行情吉凶不由你定。

目标弹窗标题为“另开货路”，说明为：

> 选择一件持有但未上架的商品。它将立即重新报价，并可能触发突发事件。

## 职业名称与局外文案

职业名称统一为三个汉字：

| ID | 新名称 | 四字箴言 |
| --- | --- | --- |
| `useless` | 生意人 | 大道至简 |
| `toothMerchant` | 牙行商 | 奇货可居 |
| `travelingMerchant` | 行脚商 | 货走四方 |
| `speculator` | 投机客 | 闻风下注 |
| `saltIronMonopoly` | 盐铁商 | 利出一孔 |

局外职业选择只承担快速比较职责。每项固定显示：职业名、四字箴言、一句角色宣言、三个短标签和专属手段名称，不展示完整数字说明。

### 生意人

> 不借势，不设局。低处敢买，高处舍得卖，就是全部本事。

标签：`标准交易`、`没有特权`、`没有代价`。专属手段：无。

### 牙行商

> 行情不肯来，就把行情做出来。只是货能抬价，也能砸在自己手里。

标签：`低价收货`、`主动抬价`、`失败封货`。专属手段：抬价。

### 行脚商

> 货压在仓里不值钱，走到有买主的地方，才真正算一门生意。

标签：`库存回市`、`重新报价`、`成交路费`。专属手段：赶集。

### 投机客

> 一条消息，他敢吃两遍。风向若是不改，赚的是胆量；风向若变，赔的也是胆量。

标签：`消息续场`、`追涨追跌`、`风险放大`。专属手段：煽风点火。

### 盐铁商

> 天下货路尽数舍去，只守四门生意。路越窄，价差越狠。

标签：`四货专营`、`行情放大`、`机会稀少`。专属手段：风向标。

## 局内职业说明

局内职业面板完整显示一句玩法判断、职业本事、主动手段和明确代价。所有数值必须来自与执行逻辑相同的结构化配置，不在文案和函数中分别手写。

### 生意人 · 大道至简

- 判断：没有门路，也没有靠山。只凭眼力，在九十天里把小生意做大。
- 本事“本分生意”：商品、货架、价格、事件和经营压力全部采用标准规则。
- 手段：没有职业主动技能，仅有每局 3 次通商令。
- 代价：没有职业优势，也没有职业限制。

### 牙行商 · 奇货可居

- 判断：不等待高价，先找到便宜货，再决定是否亲手造势。
- 本事“低价收货”：普通行情每日额外向低价偏移约 3.4%，价格下限降低 8 个百分点，自然高价不超过锚点的 110%。
- 手段“抬价”：每 3 天一次；80% 成功。成功后至少达到锚点 115%，至少比当前倍率提高 5 个百分点，最高为锚点 145%。
- 代价“封货”：20% 失败。失败当天及随后两天禁止出售，第四天恢复；强制清算不能绕过。

### 行脚商 · 货走四方

- 判断：市场不来找你，就带着货去找市场。
- 本事“熟门熟路”：若当天没有任何持仓商品自然上架，65% 概率带回压货金额最高的商品，并替换一个无库存货架位置。
- 手段“赶集”：每 3 天一次；任意持仓均可重新报价，未上架则追加上架，已上架则原地刷新；15% 概率触发普通突发事件，本次报价绕过当日生态目标价。
- 代价“路费”：赶集商品当天卖出扣除成交收入的 5%，未卖出不收费。

### 投机客 · 闻风下注

- 判断：消息落地只是开始，真正的赌注在下一阵风。
- 本事“追风”：自然突发事件商品第二天必定占用一个正常货架位置。
- 手段“煽风点火”：每 3 天一次；指定当天自然突发商品，第二天 70% 延续原方向、30% 反转，必定产生实际涨跌且不会升级为稀有事件。
- 代价“风声放大”：自然突发事件的对数价格偏离额外放大 20%，生态行情不受影响。

### 盐铁商 · 利出一孔

- 判断：天下货物虽多，只守四门生意，把每一次行情做到极致。
- 本事“专营行情”：只能交易食盐、钢材、精密机床、月壤；四种商品的普通、突发、生态和回归偏离使用 3 倍对数幅度，即标准倍率 `f` 显示为 `f³`。
- 手段“风向标”：每 7 天一次；没有生态行情时，从已解锁且至少包含一种专营商品的生态事件中随机召来一项，当天预告、下一天进入第一阶段，不能指定商品、分支或方向。
- 代价“专营限制”：其他商品即使上架也不能交易；月壤仍需本局历史最高资产达到 1,000 万后解锁。

## UI 范围

必须同步更新以下所有职业相关触点：

- 首页规则与开场职业引入。
- 职业选择弹窗、职业选项和锁定文案。
- 局内职业面板的标题、判断、本事、手段、代价和数值强调。
- 通商令按钮、剩余次数、禁用状态、目标弹窗、成功播报和无目标提示。
- 职业主动技能按钮、冷却状态、目标弹窗和结果提示。
- 新闻弹窗、队列通知、经营日志、每日历史和成就中的旧职业名。
- 新游戏、继续游戏和旧存档载入后的显示名称。

局外职业选项保持相同结构和近似高度；局内允许信息更丰富，但通商令按钮附近只显示一行简短说明。手机端按钮和数字不得因职业名称或剩余次数变化而换行抖动。

## 数据与状态

- 在职业定义中增加箴言、局外宣言、短标签以及结构化的局内规则段落。
- 将现有职业概率、倍率、冷却和费用提取为共享规则数据，执行逻辑和文案格式化共同读取。
- 新增通用行动配置和局内状态，记录最大次数 3 与已使用次数。
- 旧存档缺少通商令状态时补为本局剩余 3 次，不改变现有职业冷却和职业数据。
- 职业 ID 与存档 ID 保持不变，仅改变玩家可见名称，避免存档迁移风险。

## 验证

- 通商令合法目标、三次总量、同日多次、次日退场和失败不扣次数。
- 重新报价、15% 事件、随机方向、稀有事件、生态优先级及职业事件修正。
- 所有职业均拥有通商令，且不影响职业主动技能冷却。
- 局外文案结构统一、局内准确显示全部实际数值，代码中不存在旧职业名的玩家可见残留。
- 桌面和手机端职业选择、职业面板、两个技能按钮与目标弹窗不溢出、不跳动。
- 完整自动化测试与后台职业平衡抽样。
