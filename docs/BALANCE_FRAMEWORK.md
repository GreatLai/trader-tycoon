# 无用之人纯交易量化框架

> `useless-trader-v1` 报告已按 v1.16.0 当前价格与经营压力完整重生成。1,000 个独立验证种子下，熟练策略存活率 69.8%，存活局最终资产中位数 80,039,298 元，处于既定容差内。

## 目标与边界

本框架只衡量“无用之人”的交易能力。模拟器复用游戏真实的买卖、上架、价格、突发事件、生态事件、仓储费、强制平仓、财富里程碑、仓容和破产代码，但采用独立的纯市场随机流推进日期。

明确排除：

- 每日手牌和任何未来职业技能。
- 玩家不可见的未来价格信息。

基准锚点是熟练策略约 65% 存活到第 90 天，存活局最终资产中位数约 1 亿元。验收容差为存活率 60% 至 70%，资产中位数 0.75 亿至 1.25 亿元。

## 规则审计

### 商品与价格锚点

市场共有 20 种商品，覆盖低价到超高价档位。每种商品独立配置基础价、波动、均值回归、趋势惯性、事件敏感度和上架权重，玩家端以模糊标签公开其长期特质。

自然波动使用对数价格因子和均值回归。普通状态向基础价回归系数为 0.18，事件余震状态为 0.35；各档商品日常波动率从 0.10 递减到 0.01。普通状态价格限制在基础价的 0.8 至 1.2 倍，事件和生态状态全局限制在 0.02 至 50 倍。

基础价统一缩放 ±20% 的同种子实验表明，名义最终资产大致随锚点同比变化，但存活率仅变化数个百分点。基础价会改变整数可买数量和名义财富，不是风险结构失衡的根源，因此本轮不调整商品基础锚点。

### 突发事件

每天先抽取 0 至 3 个目标，原始分布为 20%/40%/30%/10%。目标还要通过档位移动概率：低/中档 85%，高档 70%，超高档 55%。自然事件利好概率低于利空概率，普通事件为 38%，超高档为 22%；稀有事件概率为 6%。

突发事件先计算当日无事件价格，再执行双基准方向冲击：利好从昨日实际价和当日基准价中的较高者上涨，利空从两者中的较低者下跌。旧锚点倍率改为相对冲击后，对数强度重新标定为 `1.30`，以保留可见机会和高分尾部。

### 生态事件

第 8 至 83 天、当前没有生态事件时，每日有 20% 概率启动一个可解锁事件。事件先公告，随后 A/B/C 分支连续影响价格；普通基准使用偏向温和分支的加权抽样。每阶段保留相对商品锚点的目标价格高度，同时以本阶段目标相对上一阶段目标的倍率约束当天方向，因此新闻所示涨跌与实际逐日变化一致。事件期间市场从 6 个货架扩展到 7 个。

生态倍率的对数强度缩放为 `0.92`。敏感性实验显示，生态概率和强度对财富中位数的影响远大于自然波动，是主要收益来源杠杆之一。

### 货架与套牢

常规市场每日随机上架 6 种商品，生态事件期间上架 7 种。未上架库存不能主动出售，估值使用上次可见价格。

未上架库存仍不能主动出售。只有现金无法支付当日支出时，债务清算才能处理这些库存，且仅按实际购入均价的 20% 成交。这为未上架库存保留极低的求生价值，但不消除套牢损失。

### 仓储、强平与破产

经营费分为六个固定账期：第 1-15 天每日 84 元、第 16-30 天 336 元、第 31-45 天 1,680 元、第 46-60 天 8,400 元、第 61-75 天 33,600 元、第 76-90 天 120,960 元，90 天累计 2,475,900 元。当天经营费与仓储费一并在结束当日时结算；第 90 天也必须完成最终费用结算。

剩余经营压力逐日汇总当前阶段及后续阶段的经营费。它代表从当前日期到第 90 天仍需支付的固定经营费用，为后续衡量“有效安全点”和主动重新承担风险提供统一尺度。

旧代码存在一个无效参数：`STORAGE_FEE_PER_UNIT` 声明为 0.05，但实际公式硬编码为 `数量 × 基础价 × 0.001`。现已用 `BALANCE_CONFIG.STORAGE_FEE_RATE = 0.001` 驱动真实结算，默认数值保持原实际费用。

现金不足时，系统优先按当日市价 100% 清算已上架库存；仍不足时，再按实际购入均价的 20% 处理未上架库存。系统只卖出足以支付当日支出的最少数量，并保留牙商禁售、行商路费等成交约束；全部可清算库存仍不足时立即破产。

财富里程碑自动扩仓，从 1,000 单位逐级增长至 16,000,000 单位。仓容扩大提高收益上限，也会放大按基础价计提的仓储费用。

## 策略模型

| 策略 | 可解释行为 |
| --- | --- |
| `wait` | 全程不交易，验证现金和时间基线。 |
| `random` | 随机商品、随机方向，单次最多使用 70% 现金。 |
| `allIn` | 每天清理可卖旧仓，买满绝对单价最低商品。 |
| `diversified` | 最多三仓，买相对低估商品，保留 15% 现金。 |
| `disciplined` | 只买九二折以下，盈利 12% 或明显高估即卖，仓位上限 70%。 |
| `skilled` | 结合成本、基础价、突发和生态信号，持有两仓，保留 0.95% 资产现金。 |
| `extreme` | 只追最深跌幅和利空，满仓等待翻倍或利好。 |

策略只读取玩家当日可见状态。`skilled` 的现金缓冲是模型定义而非职业加成；它的敏感性单独报告，避免把策略假设误当成市场参数。

## 指标定义

- 存活率：第 90 天以 `gameOver === 'time'` 结束的比例。
- 最终资产：现金加库存的最后可见价格估值；分布只对存活局统计，同时保留全部局分布。
- 破产日：破产局的游戏日期分布。
- 强平：发生库存被结算代码自动减仓的天数和数量。
- 最大回撤：相对历史峰值资产的最大跌幅。
- 现金危险：现金低于七天预计仓储费或当前资产 3% 的天数。
- 满仓：库存达到当前仓容 90% 的天数。
- 套牢：持仓存在但所有持仓均未上架的天数。
- 操作密度：买入和卖出动作数除以存活天数。
- 收益来源：已实现交易损益、自然价格变化、突发事件、生态事件、仓储费用和强平折价损失。

收益来源是解释性归因，不要求逐分对齐最终资产：交易归因使用卖出时成本，价格归因使用跨日持仓，二者在换仓日可能覆盖不同时间窗。

## 种子与实验纪律

- 校准池：400 个固定伪随机种子，只用于选择参数。
- 验证池：1,000 个不同固定伪随机种子，只在参数冻结后用于验收。
- 市场随机、策略随机和初始状态随机由同一局种子派生为三个独立流。
- 已移除的历史道具系统不参与模拟，也不会消耗随机数或改变后续市场路径。
- 当前 v1 报告的敏感性实验使用同一批 300 个验证种子逐项只改一个参数，报告存活率差值和条件资产中位数；解读大幅改变存活率的场景时，应同时注意幸存者构成变化。

## 运行方式

```powershell
npm test
npm run balance
npm run balance:report
```

`npm run balance` 输出校准池七策略 JSON。`npm run balance:report` 重新运行完整验证和敏感性实验，覆盖生成：

- `docs/balance/useless-trader-v1.md`
- `docs/balance/useless-trader-v1.json`

## 当前验收结论

v1.16.0 在 1,000 个验证种子下，`skilled` 无用之人策略存活率为 69.8%，存活局最终资产中位数为 80,039,298 元，P90 为 887,787,525 元，满足 60%-70% 存活率和 0.75 亿-1.25 亿元中位数的验收范围。

当前商品基础价格无需调整。若未来需要改变生存难度，优先调整仓储费率、货架可强平规则或熟练策略现金缓冲；若需要改变存活玩家的财富量级，优先调整生态事件概率/强度和突发事件强度。不要用卡牌收益补偿无用之人基准。
